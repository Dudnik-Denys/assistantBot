## На что смотреть

Правила — источник истины; список ниже — где чаще всего бывают расхождения, а не замена правил.

- Расположение: `ui/<группа>/` — общие, не знают о предметной области; `<раздел>/` — компоненты раздела, не используют компоненты другого раздела; импорты через `#lib/components/…`.
- Props: `interface Props` в компоненте, комментарий о компоненте над ним, `/** */` у неочевидных props, общие части — `extends ClassProp`, пробрасывающие атрибуты — `extends HTML…Attributes`.
- Стили: только Tailwind; цвета только токенами ролей (никаких hex, палитры Tailwind, `bg-white`); длинный `class` — массивом по группам в порядке из правил; внешний `class` — только через `mergeClasses()`; `style:` — только CSS-переменные; arbitrary values — разовые.
- `app.css`: литералы только в `:root` и по одному разу, токены ролей в `@theme inline` без литералов, имена по роли; неиспользуемые токены — «лишнее»; новые токены отступов зарегистрированы в `classes.ts`.
- Дублирование разметки, которую пора вынести в компонент `ui/`; хардкод текстов в `ui/` вместо props.
- Доступность: у кнопок-иконок `aria-label`, у полей подписи, роли и уровни заголовков.
